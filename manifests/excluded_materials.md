# Excluded Materials

This code supplement does not include:

- raw corpora or source text;
- generated outputs and result tables;
- BERTopic model folders;
- embeddings or vector arrays;
- evidence workbooks and manual-review workbooks;
- Colab input/output bundles;
- restored download staging folders;
- smoke tests, pilots, and exploratory branches outside the final paper route.

The `.gitignore` file is configured to keep these materials out of the
repository if compatible data are placed locally for review.
